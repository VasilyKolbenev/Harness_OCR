# Проверить Харнесс OCR на своих документах

RC6 запускается на Linux с Docker Compose, NVIDIA Container Toolkit и Python 3.12+ на хосте. На хосте не нужны зависимости нейромоделей. Цель — RTX PRO 5000 Blackwell 48 GB. Требования и ограничения: [README_LINUX_GPU.txt](../README_LINUX_GPU.txt).

```bash
git clone --branch delivery/gpu-rc6 https://github.com/VasilyKolbenev/Harness_OCR.git
cd Harness_OCR
bash scripts/gpu_handoff.sh --input /absolute/path/to/documents --profile D07 --output "$PWD/reports/run-001"
```

В папке должны быть только документы одного профиля: D07 — платёжное извещение. Для других документов выберите профиль из [каталога](supported-documents.md). Для разных типов используйте явный `--manifest`; формат в основной инструкции. Один файл — один документ. До 100 файлов, 30 MiB на файл; растровый тракт ограничен 10 страницами и 12 млн пикселей на страницу. Не меняйте исходники во время выполнения.

Команда соберёт образ с YOLO, скачает закреплённые веса, проверит CUDA и выполнит настоящий GPU smoke. Затем сравнит Qwen 0.8B и 4B с DB и DB+YOLO-L: четыре варианта, без параллельных моделей. `--include-yolo-x` добавит ещё два. Во всех сохраняются Xiaomi, перечитывание, визуальный verifier и строгие проверки. На сравнение по умолчанию отведено 3 часа; сборка, загрузка и smoke имеют отдельные бюджеты. На каждый запуск нужен новый `--output`; модели используются повторно. `--qwen qwen-0.8b` или `--qwen qwen-4b` оставляет два варианта и готовит только выбранную Qwen.

Прислать команде **`reports/run-001/RETURN_TO_TEAM.zip`**. В нём HTML, CSV и безопасная сводка, без сканов, значений полей, исходных имён, эталонов, приватных логов и трасс. Даже при сбое архив нужен для диагностики. Полную папку с реальными документами не пересылайте автоматически.

Без эталонов оцениваем выполнение, покрытие, review, скорость и ресурсы. Для точности добавьте отдельный `--gold /path/gold.json` по формату основной инструкции. Gold v1 оценивает только дословные скалярные строки; значения не поступают моделям. Неразмеченные поля остаются без оценки. Для gold предпочтителен manifest со стабильными ID; при `--input` карта `doc-0001` и далее по сортировке имён хранится в приватном `private-input-map.json`. Пример ключа D07: `payer.name`. Технически завершённый документ с `review` не означает точное распознавание. Автоматическое принятие полей закрыто.

Уже работающий OCR-сервис нужно штатно остановить перед сравнением. Скрипт не останавливает чужие процессы. Все запуски на одной карте должны использовать общий volume `harness-ocr-device-locks`. Для диагностики не нужно менять код или включать свободную генерацию Qwen.
